## Цель работы
Создать эмулятор терминала с поддержкой виртуальной файловой системы и рядом базовых команд.

## Структура проекта
- `main.py` — точка входа, обработка пользовательских команд.
- `vfs.py` — реализация виртуальной файловой системы.
- `commands/` — директория с реализациями команд:
    - `ls.py` — вывод содержимого директории
    - `cd.py` — смена текущей директории
    - `mkdir.py` — создание директории
    - `touch.py` — создание файла
    - `pwd.py` — вывод текущей директории
    - `tree.py` — древовидный вывод структуры
    - `echo.py` — вывод текста
    - `exit.py` — завершение работы
- `osScripts/` — примеры скриптов для реальной ОС
- `startupScripts/` — примеры стартовых скриптов эмулятора

## Описание реализованных команд
- **ls** — выводит список файлов и папок в текущей директории
- **cd** — изменяет текущую директорию
- **mkdir** — создаёт новую директорию
- **touch** — создаёт новый файл
- **pwd** — показывает путь к текущей директории
- **tree** — отображает структуру каталогов в виде дерева
- **echo** — выводит текст в консоль
- **exit** — завершает выполнение программы

## Примеры использования
```
> mkdir test
> cd test
> touch file.txt
> ls
file.txt
> pwd
/test
> tree
└── test
    └── file.txt
> echo Hello, world!
Hello, world!
> exit
```
